# Script Demo Video — Shelfly

Durasi target: 6-8 menit. Rekam langsung interaksi aplikasi (buka app -> klik -> input -> lihat hasil). Tanpa slide, tanpa teori, tanpa kode.

Pembagian: 4 orang, masing-masing perkenalan singkat (nama + peran) lalu langsung demo modul masing-masing.

---

## 1. Nadine — UI, Home, Shelves, Multi-select (~2 menit)

**Perkenalan:** "Hai, saya Nadine, bagian UI — Home, Shelves, dan navigasi."

**Demo:**
1. Buka app, tunjukkan Home: greeting, search bar, "My Shelves", "Recently Opened".
2. Tap "See all" di My Shelves → masuk tab Shelves.
3. Tap "See all" di Recently Opened → masuk tab Recent.
4. Balik ke Shelves, tap ikon pensil di salah satu Shelf card → edit nama Shelf → Simpan.
5. Masuk ke salah satu Shelf (Shelf Detail), long-press salah satu Material → masuk mode multi-select (checkbox muncul).
6. Pilih 2-3 Material, tunjukkan toolbar atas (pindah / hapus), tap ikon pindah → pilih Shelf tujuan.
7. Tap ✕ untuk keluar mode select.
8. Tunjukkan tombol Import Material sudah jadi floating action button (+) di kanan bawah.

---

## 2. Rifky — Database, Shelf CRUD (~1.5 menit)

**Perkenalan:** "Saya Rifky, bagian database dan Shelf — create, edit, delete, persistence."

**Demo:**
1. Dari Shelves, tap "+" → buat Shelf baru, isi nama → Simpan.
2. Tunjukkan Shelf baru muncul di list.
3. Tap ikon pensil pada Shelf → ubah nama → Simpan, tunjukkan nama berubah.
4. Tap ikon delete pada Shelf lain → konfirmasi dialog → Hapus, tunjukkan Shelf hilang beserta Material di dalamnya.
5. Tutup app sepenuhnya (recent apps → swipe close), buka lagi → tunjukkan data Shelf masih ada (Room persistence).

---

## 3. Intan — File Management, Add Material, Preview (~2 menit)

**Perkenalan:** "Saya Intan, bagian file management — import, preview, dan viewer."

**Demo:**
1. Masuk salah satu Shelf, tap FAB "+" → Add Material.
2. Pilih 1 file (PDF/gambar) → tunjukkan preview langsung muncul dengan ilustrasi upload sebelumnya.
3. Simpan, tunjukkan file masuk ke list Shelf.
4. Tap FAB lagi, kali ini pilih banyak file sekaligus → tunjukkan daftar preview (nama file + tipe) muncul SEBELUM commit.
5. Tap "Import N File" untuk konfirmasi semua masuk.
6. Buka salah satu Material (PDF atau gambar) → tunjukkan in-app viewer, pinch-zoom + pan.
7. Tap share → tunjukkan share sheet Android muncul.

---

## 4. Yunan — Search, Filter, Favorite, Recent (~1.5 menit)

**Perkenalan:** "Saya Yunan, bagian search, filter, favorite, dan recent."

**Demo:**
1. Dari Home, tap search bar → masuk Search, ketik keyword → tunjukkan hasil filter real-time.
2. Tunjukkan sort chip (Newest/dll), ganti opsi → urutan hasil berubah.
3. Tap ikon favorit (bintang) pada salah satu Material di hasil search.
4. Masuk tab Favorites → tunjukkan Material tadi muncul.
5. Masuk tab Recent → buka salah satu Material, balik, tunjukkan masuk Recently Opened.
6. Tunjukkan empty-state ilustrasi di Search/Favorites/Recent (search keyword kosong/belum ada hasil).

---

## Catatan Rekaman

- Device: Xiaomi 25080RABDG (atau device lega storage lain).
- Pastikan ada minimal 2-3 Shelf dan beberapa Material sebelum mulai rekam (biar gak banyak nunggu buat data).
- Transisi antar orang: cukup potong video, tidak perlu narasi "selanjutnya giliran si X".
- Hindari jeda lama nunggu popup konfirmasi install/permission — pause rekaman kalau perlu nunggu device.
