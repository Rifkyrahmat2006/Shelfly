# Script Demo Video — Shelfly (5 Menit)

Rekam langsung interaksi aplikasi (buka app -> klik -> input -> lihat hasil). Tanpa slide, tanpa teori, tanpa kode.

Pembagian: 4 orang, masing-masing perkenalan 1 kalimat lalu langsung demo modul masing-masing. ~1 menit 15 detik per orang.

---

## 1. Nadine — UI, Home, Shelves, Multi-select (~75 detik)

**Perkenalan:** "Hai, saya Nadine, bagian UI — Home, Shelves, dan navigasi."

**Demo:**
1. Buka app, tunjukkan Home sekilas (greeting, search bar, My Shelves, Recently Opened).
2. Tap "See all" di My Shelves → masuk tab Shelves.
3. Tap ikon pensil di satu Shelf card → edit nama → Simpan (tunjukkan nama berubah).
4. Masuk Shelf Detail, long-press satu Material → mode multi-select aktif, pilih 2 Material, tap ikon hapus → konfirmasi.

---

## 2. Rifky — Database, Shelf CRUD (~45 detik)

**Perkenalan:** "Saya Rifky, bagian database dan Shelf — create, delete, persistence."

**Demo:**
1. Dari Shelves, tap "+" → buat Shelf baru, isi nama → Simpan, tunjukkan muncul di list.
2. Tap ikon delete pada satu Shelf → konfirmasi → Hapus.
3. Tutup & buka app lagi sekilas → tunjukkan data Shelf masih ada (persistence).

---

## 3. Intan — File Management, Add Material, Preview (~90 detik)

**Perkenalan:** "Saya Intan, bagian file management — import, preview, dan viewer."

**Demo:**
1. Masuk Shelf, tap FAB "+" → pilih banyak file sekaligus → tunjukkan daftar preview (nama + tipe file) muncul sebelum commit → tap "Import N File".
2. Buka satu Material (PDF/gambar) → tunjukkan in-app viewer, pinch-zoom + pan.
3. Tap share → tunjukkan share sheet Android muncul.

---

## 4. Yunan — Search, Filter, Favorite, Recent (~50 detik)

**Perkenalan:** "Saya Yunan, bagian search, filter, favorite, dan recent."

**Demo:**
1. Dari Home, tap search bar → ketik keyword → tunjukkan hasil real-time.
2. Tap ikon favorit (bintang) pada satu hasil → masuk tab Favorites → tunjukkan Material tadi muncul.
3. Buka satu Material dari Favorites, balik → masuk tab Recent → tunjukkan masuk Recently Opened.

---

## Catatan Rekaman

- Device: Xiaomi 25080RABDG (atau device lega storage lain).
- Siapkan 2-3 Shelf dan beberapa Material SEBELUM rekam — jangan buat data dari nol saat rekam, waktu terbatas.
- Transisi antar orang: potong video langsung, tanpa narasi "selanjutnya...".
- Latihan dulu urutan tap sebelum take final — 5 menit ketat, tidak ada ruang untuk nunggu/mikir di depan kamera.
